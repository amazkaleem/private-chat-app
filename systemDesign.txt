Private Chat App

Functional Requirements:
1) Users should be able to  Sign Up/Log In with their username and password with "Session Based Auth"
2) Users are categorized into "Visitors", "Members", and "Admins"
3) Visitors can only receive messages (without author/date labels) and create new messages
4) Visitors can upgrade to Members and can view messages (with author/date labels) as well
5) Members can upgrade to Admins and can delete messages, view members list and remove them as well.
6) Only Members and Admins mark messages as read
7) Content-Type of messages = "Text"

Non Functional Requirements:
1) Scale: 100 messages per day
2) Availaibility: Always Operational
3) Latency: API Target is 100ms

Data Math:
Considering eash message is 200 Bytes:

100 * 200 = 20000 Bytes = 20KB Storage

(We only need a PostgreSQL instance)

High Level API Design:
RESTful API Design (PATCH/DELETE methods not used since HTML Forms only allow GET/POST methods)

1) Get the Home Page (the Message Board) (GET /chat-messages):
   Response:
   i) 200 Success - Render index and GET all new messages
   ii) 204 No Content - []
   iii) 500 Internal Server Error

2) Get the Login Form (GET /log-in):
   Response:
   i) 200 Success - Render Log In Form
   ii) 500 Internal Server Error

3) Get the Sign Up Form (GET /sign-up):
   Response:
   i) 200 Success - Render Sign Up Form
   ii) 500 Internal Server Error

4) Create a new User (POST /sign-up):
   Response:
   i) 302 Redirect to "/chat-messages"
   ii) 400 Validation Errors
   iii) 500 Internal Server Error

5) Authenticate Login Details (POST /log-in):
   Response:
   i) 302 Redirect to "/chat-messages"
   ii) 401 Unauthorized
   iii) 404 Not Found

6) Get a single message (GET /chat-messages/:messageid):
   Request: :messageid
   Response:
   i) 200 Success - msgContent
   ii) 404 Not Found

7) Mark as Read (POST /chat-messages/:messageid/mark-read):
   Request: :messageid
   Response:
   i) 302 Redirect to "/chat-messages"
   ii) 404 Not Found

8) Get the Members list (Admin Only) (GET /chat-members):
   Response: 
   i) 200 Success - [members]
   ii) 404 Not Found

9) Remove Members (Admin Only) (POST /chat-members/:userid/delete):
   Request: :userid
   Response:
   i) 302 Redirect to "/chat-members"
   ii) 404 Not Found

10) Delete Messages (Admin Only) (POST /chat-messages/:messageid/delete):
    Request: :messageid
    Response:
    i) 302 Redirect to "/chat-messages"
    ii) 500 Internal Server Error

11) Get Member Log In Form (GET /member-log-in):
    Response: 
    i) 200 Success - Render Member Log In Form
    ii) 500 Internal Server Error

12) Create new Member (POST /member-log-in):
    Response:
    i) 302 Redirect to "/chat-messages" (User Status Changed to "Member")
    ii) 400 Validation Errors
    iii) 500 Internal Server Error

13) Get Admin Log In Form (GET /admin-log-in):
    Response:
    i) 200 Success - Render Admin Log In Form
    ii) 500 Internal Server Error

14) Create new Admin (POST /admin-log-in):
    Response:
    i) 302 Redirect to "/chat-messages" (User Status Changed to "Admin")
    ii) 400 Validation Errors
    iii) 500 Internal Server Error
